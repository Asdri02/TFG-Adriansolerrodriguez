          Examen estructurado con Vision IA
          
          
          
            Para tablas (formulación, completar huecos), exámenes mixtos
            o cualquier cosa que Tesseract no entiende. Usa Claude Vision para
            extraer celdas, identificar qué escribió el alumno y qué venía
            impreso. Requiere ANTHROPIC_API_KEY.
          
          
          
          
            Arquitectura: Claude Vision solo extrae el contenido visual.
            La corrección se hace después con el grader determinista
            (comparación normalizada + fuzzy + sinónimos del profesor).
            Mantenemos interpretabilidad en el juicio.

                Sinónimos del profesor
                
            
                
              El grader trata como equivalentes el término canónico y sus
              variantes en cualquier respuesta. Ejemplo:
              variable ↔ identificador, var.
            
                
            
                
            
                
              
              
              
            
                
          
                

          
                
            
                Antipatrones
                
            
                
              Si la respuesta del alumno contiene una frase prohibida asociada
              a un concepto presente en la rúbrica, la nota se multiplica por
              el factor de penalización (0 a 1).
            
                
            
                
            
                
              
              
              
              
            
                
          
                

          
                
            
                
              
                Configuración persistida en el servidor
                
              
                
                
                
              
                
            
                
            
                
              Se almacena en data/teacher_config.json y afecta a
              todas las correcciones a partir del próximo grade.
            
                
          
                
        
                
      
                

      
      
                
        
                
          ⚠ Función experimental. Esta corrección delega 100 %
          en Claude y NO es interpretable como el grader principal. Está fuera
          del alcance core del TFG (la memoria menciona explícitamente que la
          corrección paso-a-paso de ejercicios cuantitativos es línea futura).
          Trátala como demostración o segunda opinión, nunca como nota oficial.
